# 임산물 재배 적합성 판정 앱

## 앱의 목적

사용자가 "지역 + 품목"을 선택하면, 지금 갱신 식재했을 때 미래 기후에서
재배가 가능한지 판정한다.

예: "군위 + 대추 + 2050년" → 위험 (2035년 위험 구간 진입, 수확기의 76%가 위험)

## 핵심 개념

임산물은 심고 나서 결실까지 수년, 그 뒤 수십 년을 간다.
따라서 식재 결정은 "지금 기후"가 아니라 "수확기의 기후"를 기준으로 내려야 한다.

- 밤:  결실 개시 5년, 경제수명 30년
- 감:  결실 개시 5년, 경제수명 30년
- 대추: 결실 개시 3년, 경제수명 25년

식재 연도는 2026년 기준 (요약 데이터의 식재/첫수확/수확종료 컬럼과 일치).

## 판정 규칙 (절대 변경 금지)

편차 = 해당 시기 생육기 기온 − 품목별 적정 생육기 기온

판정은 4단계이며, 경계값(경고임계·위험임계)은 품목별로 다르고 데이터에 포함되어 있다:

```
편차 > 위험임계            →  위험 (빨강)
경고임계 < 편차 ≤ 위험임계  →  주의 (주황)
0 ≤ 편차 ≤ 경고임계        →  경고 (노랑)
편차 < 0                   →  적합 (초록)
```

품목별 적정 생육기 기온과 임계값 (°C):

| 품목 | 적정 온도 | 경고임계 | 위험임계 |
|---|---|---|---|
| 밤 | 19.7 | 1.3 | 2.0 |
| 대추 | 19.6 | 1.8 | 2.1 |
| 감 | 20.0 | 1.4 | 1.7 |

※ 적정 온도는 주산지(재배면적 90% 커버) 면적가중 평균으로 산출.
   밤·감은 리카디안 회귀의 최적점과 일치하여 검증됨.

## 데이터

사전 계산 완료. 앱은 두 파일을 조회만 한다.

### data/앱데이터_시계열.csv (5,538행)

품목, 시도, 시군구, k2(매칭키), 적정온도, 경고임계, 위험임계, 결실개시년,
경제수명년, 현재재배면적_ha, 현재단수_kg_ha, 현재단가_원kg,
시나리오, 중심연도, 생육기기온, 편차, 판정, 저온요구도

- 시나리오: 관측(중심연도 2005, 평년값 1991-2020) / ssp245 / ssp585
- 중심연도: 관측 2005 + 시나리오별 2028, 2038, 2048, 2058, 2068, 2078
- 규모: 142개 시군구 × 3품목 × 13행(관측 1 + 2시나리오 × 6시점)

### data/앱데이터_요약.csv (852행)

품목, 시도, 시군구, k2, 시나리오, 경고진입, 주의진입, 위험진입,
식재, 첫수확, 수확종료, 현재재배면적_ha, 수확기중위험비율

- 시나리오별(ssp245/ssp585) 각 판정 단계 진입 연도와
  수확 기간(첫수확~수확종료) 중 위험 구간 비율(%)
- 주의진입·위험진입이 비어 있으면 해당 단계에 진입하지 않음
- 규모: 142개 시군구 × 3품목 × 2시나리오

## 데이터 출처 (앱 하단에 반드시 표기)

- 산림청 임산물생산조사 (생산량·생산액, 2024)
- 산림청 임산물생산비조사 (경영개황)
- 통계청 농림어업총조사 임업부문 (재배면적, 2010·2015·2020)
- 기상청 기후평년값 1991-2020 (관측)
- 기상청 SSP 기후변화 시나리오 (남한상세, ENS)

※ 미래 기후는 관측 평년값에 시나리오 변화량을 더한 델타법으로 산출

## 절대 원칙

1. 판정 기준(품목별 임계값)을 임의로 바꾸지 마라. 판정·진입연도·위험비율은
   CSV의 사전 계산값을 그대로 쓰고, 앱에서 재계산하지 않는다.
2. 없는 데이터를 추정해서 채우지 마라. 해당 시군구·품목 조합이 없으면
   "해당 지역 재배 실적 없음"으로 표시한다.
3. 예측의 불확실성을 숨기지 마라. 결과 화면에 반드시 한계를 표시한다.
4. 저온요구도는 보조 지표로만 쓴다. 주 판정은 온도 편차다.

## 기술 스택

- 단일 HTML + 바닐라 JS (빌드 도구 없이 브라우저에서 바로 열림)
- CSV 내용을 JS 객체로 index.html에 인라인 삽입 (로컬 CORS 문제 회피)
- 외부 라이브러리 없이. 차트는 순수 SVG로 그린다.
