# 임산물 재배 적합성 판정 앱

## 이 앱이 답하는 질문

- "군위에 대추를 지금 심으면 2050년에도 재배 가능한가?" → **위험** (2035년 위험 구간 진입, 수확기의 76%가 위험)
- 임산물은 심고 나서 결실까지 수년, 그 뒤 수십 년을 가므로, 식재 결정은
  "지금 기후"가 아니라 **"수확기의 기후"** 를 기준으로 내려야 한다.
- 지역·품목(밤/대추/감)을 고르면 결실 개시 시점과 수확 기간 전체의 기후 적합성을 판정한다.

## 실행 방법

`index.html`을 브라우저로 열면 끝. (데이터가 파일 안에 인라인되어 있어
서버·빌드 도구·외부 라이브러리가 전혀 필요 없음)

## 판정 기준

편차 = 해당 시기 생육기 기온 − 품목별 적정 생육기 기온. 판정은 4단계.

| 편차 | 판정 |
|---|---|
| > 위험임계 | 위험 (빨강) |
| 경고임계 < 편차 ≤ 위험임계 | 주의 (주황) |
| 0 ≤ 편차 ≤ 경고임계 | 경고 (노랑) |
| < 0 | 적합 (초록) |

품목별 적정 온도와 임계값 (°C):

| 품목 | 적정 온도 | 경고임계 | 위험임계 | 결실 개시 | 경제수명 |
|---|---|---|---|---|---|
| 밤 | 19.7 | 1.3 | 2.0 | 5년 | 30년 |
| 대추 | 19.6 | 1.8 | 2.1 | 3년 | 25년 |
| 감 | 20.0 | 1.4 | 1.7 | 5년 | 30년 |

(적정 온도는 주산지 — 재배면적 90% 커버 — 면적가중 평균. 밤·감은 리카디안
회귀의 최적점과 일치하여 검증됨)

판정·단계 진입연도·수확기 중 위험 비율은 `data/`의 CSV에 사전 계산되어
있으며, 앱은 이 값을 **조회만** 하고 재계산하지 않는다. (기준 불일치 방지)

## 한계

- 본 판정은 **생육기 평균기온 기준의 1차 스크리닝**이다. 실제 재배 가능성은
  토양·품종·재배기술·병해충에 따라 달라진다.
- 미래 기후 시나리오는 **불확실성**을 포함한다.
- 2040년대 이후 예측 기온은 **현재 국내에 유사 사례가 없는 구간**이며,
  따라서 판정은 방향성 참고용이다.
- 적정 온도와 품목별 임계값은 **현재 주산지의 기후에서 역산**한 값이다.
- 저온요구도는 보조 지표로만 쓰며, 주 판정은 온도 편차다.
- 없는 데이터는 추정하지 않는다. 재배 실적이 없는 시군구·품목 조합은
  "재배 실적 없음"으로 표시한다.
