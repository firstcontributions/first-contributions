# 발표 자료 — 양돈 AI 발정 탐지·번식 문제 진단

심사 발표용 슬라이드 구성 + 스피커 노트. 각 슬라이드는 대시보드 화면과 1:1로
연결된다(발표 시 `dashboard/index.html`에서 해당 뷰를 띄우며 설명).

## 슬라이드 1 — 문제 정의 (30초)
**"발정을 놓치면 번식이 무너진다."**

- 이유 후 발정지연·무발정·미약발정 → 수태율↓, 비생산일수(NPD)↑, 도태율↑
- 원인: 영양 부족 · 더위 스트레스 · 수퇘지 자극 부족 · 잘못된 사양관리
- 특히 **미약(둔성)발정**은 육안으로 놓치기 쉬움 → **CCTV·AI의 가치가 최대**

> 스피커: "농장의 번식 손실 대부분은 발정 관찰 실패에서 옵니다. 사람 눈으로는
> 미약발정을 놓치죠. 그래서 CCTV로 24시간 관찰하고 AI가 판정합니다."

## 슬라이드 2 — 접근: 관찰→진단→예측 (40초)
```
CCTV → [탐지] → [추적/활동] → [행동 인식] → [발정 판정] → [번식 진단·조기경보]
```
- **①관찰**: 탐지(YOLO)·개체 추적(IoU+Re-ID)·행동 인식·활동 분석
- **②진단**: AI Hub 71471 발정 표준으로 판정 → 문제 3종 분류 + 원인 4종 귀인 + 처방
- **③예측**: 발정 예상일(D-day) 조기경보 + 지연/무발정 조기 포착

> 차별점: "단순 발정 탐지가 아니라, **원인을 지목하고 며칠 앞서 경보**합니다."

## 슬라이드 3 — 데모 ①: 번식 진단·조기경보 대시보드 (60초)
화면: `repro_dashboard.html`

- 번식 문제 유형 분포 (미약발정 49% ← CCTV 가치 강조)
- 위험군 원인 4종 기여 (사양관리 36·영양 27·수퇘지 20·더위 14%)
- **발정 조기경보 타임라인** — 유형별 궤적 + D-day/경보 마커
- 개체별 종합 진단표 (위험%·문제유형·주원인·처방)

> "이 개체는 위험 99%, 이유후 발정지연, 주원인은 수퇘지 자극 부족 →
> 처방은 성숙 웅돈 1일 2회 대면 노출. 여기까지 자동입니다."

화면: `eval_report.html`

| 지표 | 값 | 검증 |
|---|---|---|

> "낮은 숫자도 **개체 분리로 정직하게** 측정했습니다. 혼동행렬·ROC·PR·보정곡선을
> 다 공개합니다. 발정 관찰의 핵심인 활동/휴식 구분은 AUC 0.739로 견고합니다."

## 슬라이드 7 — 기존 상용 제품 대비 포지셔닝 (50초)

상용 스마트양돈 솔루션(RFID 활동량 기반 발정탐지, 통합 사양관리 시스템 등)과
비교해 **우리가 채우는 빈칸**과 **의도적으로 다루지 않은 영역**을 구분한다.

| 항목 | 기존 상용 제품 | 본 프로젝트 |
|---|---|---|
| 발정 **탐지** | ✅ 성숙(활동량 기반) | ✅ CCTV 행동 기반 |
| 발정 **원인 진단** | ⚠️ 약함 — "발정 왔다/안 왔다"에 그침 | ✅ **원인 4종 귀인 + 개체별 처방** |
| **미약(둔성)발정** | ⚠️ 놓치기 쉬움 | ✅ 낮은 상승 추세로 선제 포착 |
| 발정 **예상일(D-day)** | ⚠️ 드묾 | ✅ **추세 외삽, 리드타임 +1.8일** |
| 개체 식별 | RFID 이표(확실·설치비↑) | 영상 Re-ID(**무센서·저비용**, 일관성 0.77) |
| 도입 비용 | 이표·센서·급이기 설치 필요 | **기존 CCTV 활용** |
| 평가 투명성 | 정확도만 홍보, 검증법 비공개 | ✅ **개체 분리 검증·보정곡선 공개** |
| 실시간 알람·모바일 | ✅ 성숙 | 🟡 경보 콘솔·푸시 목업(발송 연동 미구현) |
| 하드웨어 제어(쿨링·급이) | ✅ 자동 연동 | ⬜ 처방 텍스트까지 |
| 번식 전주기·ERP | ✅ 임신·분만·이력제 통합 | ⬜ 발정 구간에 집중 |
| 실농장 실증 | ✅ 수년간 수태율 검증 | ⬜ 미실시(데이터 적합성은 실측 규명) |

**핵심 메시지 3줄**
1. 상용은 *"발정이 왔다"* 까지 — 우리는 ***"왜 안 오는지, 어떻게 고칠지, 언제 올지"***
2. 추가 센서 없이 **기존 CCTV만으로** → 중소농가 진입장벽 해소
3. 검증 방법을 **투명하게 공개** → 과장 없는 신뢰

> 스피커: "상용 제품과 경쟁하려는 게 아니라 **비어 있는 칸을 채웁니다**. 상용은
> 탐지에 강하지만 원인 진단과 미약발정, 그리고 저비용 진입에는 약합니다.
> 하드웨어 제어나 ERP 통합은 저희가 다루지 않은 영역임을 분명히 합니다."

## 슬라이드 8 — 차별점 (30초)
1. **진단까지** — 발정 탐지를 넘어 문제 유형·원인·처방으로 실행 가능
2. **조기경보** — 발정 예상일(D-day)을 며칠 앞서, 지연/무발정을 놓치지 않음
3. **신뢰도** — 개체 분리 검증 + 보정곡선까지 공개(낙관 편향 배제)
4. **재현성** — 22개 스모크 테스트, 자체완결 대시보드, 연결 없이 실행

## 슬라이드 9 — 한계와 향후 (30초, 정직하게)
- 발정 판정은 미완 — 단, **왜 안 되는지 실측으로 규명**(라벨에 발정 지시 행동 부재).
  원천 동영상 또는 외음부 이미지 원천 확보가 다음 단계
- 행동 인식 0.49 → 포즈/시퀀스 모델로 개선 여지
- 도메인 격차(연구용↔상용 돈방) → 국내 데이터 파인튜닝
- 향후: 71763 센서로 원인 귀인 실측, 처방 효과 폐루프 검증

> "과장하지 않습니다. 무엇이 검증됐고 무엇이 남았는지 명확히 구분했습니다."
