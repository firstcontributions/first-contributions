# 🐖 양돈 AI — 발정 탐지·번식 문제 진단 파이프라인

돈방 CCTV 영상으로 **돼지를 탐지 → 개체 추적 → 행동 인식 → 발정 판정**하고,
나아가 **번식 문제(이유후 발정지연·무발정·미약발정)를 진단하고 원인을 지목해
처방**하는 머신러닝 파이프라인. AI Hub 71471 발정행동 데이터를 **판정 표준**으로
삼고, 원격에서 바로 실험 가능한 케글 공개 데이터로 검증한다.

```
CCTV → [탐지] → [추적/활동] → [행동 인식] → [발정 판정] → [번식 진단·조기경보]
        YOLO     IoU+Re-ID     기하+모션+외형   71471 표준    문제3종·원인4종·D-day
```

> **왜 발정인가.** 발정 적기 포착은 수태율·비생산일수(NPD)를 좌우하는 번식효율의
> 핵심이다. 특히 **미약(둔성)발정**은 육안 관찰이 놓치기 쉬워 CCTV·AI의 가치가
> 가장 큰 지점이다.

## 핵심 성과 (실데이터·개체 분리 검증)

| 과제 | 지표 | 값 | 검증 |
|---|---|---|---|
| 행동 인식(외형+시간윈도우) | 정확도 / Macro-F1 | **0.516 / 0.386** | 개체 분리 GroupKFold(5) |
| 돼지 탐지기(직접 학습) | mAP50 | **0.659** | pig-detection 3,743장 학습 |
| 활동 vs 휴식(이진, 발정 관찰 기반) | ROC-AUC / Brier | **0.739 / 0.174** | 개체 분리 GroupKFold(5) |
| 자세 인식(5클래스) | 정확도 | **0.642** | train1→train2 held-out |
| 개체 추적(Re-ID) | 단편화 감소 | **-46%** (107→58 트랙) | GT ID 일관성 0.77 |
| 발정 조기경보 | 문제 조기포착 재현율 | **1.00** (정밀도 0.67) | 합성(도메인 관계) |
| 발정 조기경보 | 임박 리드타임 | **+1.8일** 선제 | 합성 |
| **71471 발정 실측 검증** | AUC | **0.465** | ✅ 완료 — 카메라·개체 통제(아래 참조) |

> 실데이터(케글)는 절대 수치가 낮아도 **개체 분리로 정직하게** 측정했다. 활동/휴식
> 구분(AUC 0.739)이 견고한 것이 발정 관찰의 실질 기반이다.

## 파이프라인 3축

### ① 관찰 (Observation)
- **탐지**: pig-detection(YOLO) 45,611 bbox, 8개 소스. `build_detection_viewer.py`
- **추적**: IoU + 외형 Re-ID(HSV·gradient 40D + 위치 게이트)로 개체 ID 부여,
  가림에 의한 단편화 46% 감소. `iou_tracker.py`
- **행동 인식**: 기하+모션 → **외형 + 시간윈도우** 조합으로 0.432→**0.516** 개선
  (둘이 상보적: +시간 0.471 / +외형 0.491 / **둘 다 0.516**).
  `model_behavior_appearance.py`, `temporal_features.py`
- **탐지기 자체 학습**: pig-detection 3,743장으로 YOLOv8n 학습(mAP50 0.659) →
  **임의 영상에 바로 적용 가능**. `models/pig_yolo.pt`, `train_pseudo_label.py`
- **활동 분석**: 점유 heatmap·마릿수·활동량 추이. `build_activity_analysis.py`

### ② 판정·진단 (Diagnosis)
- **발정 표준(71471)**: 승가·꼬리세움·기립반사 등 수의학 근거 가중치로 발정 점수화.
  실데이터 발정 정답이 오면 지도학습으로 보정. `aihub_estrus_reference.py`
- **개체별 발정 타임라인**: 추적 ID별 발정 점수 시계열. `build_estrus_timeline.py`
- **번식 문제 진단**: 블랙박스 무발정 확률을 **문제 3종 × 원인 4종**의 실행 구조로
  전환 — 문제 유형 분류 + 원인 귀인 + 개체별 처방. `repro_cause_attribution.py`
  - 문제: 이유후 발정지연 · 무발정 · 미약(둔성)발정
  - 원인: 영양(등지방·사료) · 더위스트레스(THI) · 수퇘지자극 · 사양관리

### ③ 예측 (Prediction)
- **발정 조기경보**: 이유 후 일 단위 발정 준비도 추세를 외삽해 **발정 예상일(D-day)**
  선제 경보 + 정상 WEI(7일) 초과·무발정 조기 포착. `estrus_early_warning.py`
- **CCTV→무발정 융합**: 관찰 신호 + 관리요인 융합 위험 예측 + 처방. `pipeline_gilt.py`

### 판정 표준 — AI Hub 71471 (소·돼지 발정행동)

가장 중요한 발견이다.

#### 실측 결과 — 이 서브셋으로는 발정 판정이 불가하다 (근거 확보)

세 단계로 엄격도를 높이며 측정했다(`estrus_contrast_eval.py`, 전체 33,600파일에서
조건을 만족하는 7개체·2,492프레임 선별):

| 설계 | 통제 수준 | AUC |
|---|---|---|
| ① 돈방 라벨 + bbox 기하 | 없음 | ~1.00 ← **가짜(카메라 암기)** |
| ② 개체 내 대조 · 행동만 | 카메라 교락 제거 | 0.579 |
| **③ 채널 고정 · 행동만** | **카메라·돈방·개체 전부 통제** | **0.465** |

- `ESTRUS` 라벨은 **개체가 아니라 돈방/카메라 단위**였다(ch1~8 전부 발정,
  ch9~16 전부 비발정). 기하 피처를 쓰면 AUC 1.0 이 나오지만 **못 본 카메라에서는
  0.409 로 무너져** 카메라 암기였음이 드러난다.
- 외음부 라벨(`ANIMAL_ID`+`DATE`, 22,497건·175개체)을 **발정 달력**으로 삼아
  bbox 와 연결해, 같은 개체의 발정일 vs 비발정일 대조를 구성했다
  (`estrus_calendar.py`). 같은 카메라에서 발정 상태만 바뀌는 최상 조건에서도
  **무작위 수준(0.465)**.
- 원인은 모델이 아니라 **라벨 어휘**다. 이 서브셋 행동은 4종
  (`lying·standing·sitting·eating`)뿐이고 **발정 지시 행동(tailing 꼬리세움·
  mounting 승가·기립반사)이 주석에 없다.** 단일 프레임 자세로는 활동량 변화도
  담기지 않는다.

> 이는 실패가 아니라 **데이터 적합성에 대한 실측 근거**다. 검증기는 이런 교락을
> **자동 탐지**해 누수된 AUC 를 보고하지 않는다(`validate_estrus_reference.py`).
> 발정 판정에는 ① 원천 **동영상**(활동량 시계열) ② 발정 지시 행동이 포함된 주석
> ③ 외음부 **이미지 원천** 중 하나가 필요하다. 상세: [`docs/AIHUB.md`](docs/AIHUB.md)

## 국내 실축사 영상 검증 (적용 조건 규명)

직접 학습한 탐지기로 국내 모돈사 영상을 처리해 **어디서 되고 어디서 안 되는지**를
실측했다(`analyze_video.py` — 영상을 넣으면 리포트가 나오고, 촬영 조건을 자동 진단).

> 📌 검증에 쓴 외부 영상은 **참고 자료**이며 제출물·앱에 포함하지 않는다(저작권).
> 분석기 산출물은 `outputs/` 에 생성되고 통합 대시보드와 분리돼 있다.

| 조건 | 판정 | 근거 |
|---|---|---|
| 탐지 | ✅ 국내에서도 동작 | 미탐지 0프레임, 신뢰도 최대 0.97 |
| **군사(群飼) 사육** | ✅ **필수** | 활동량 군사 14.0px vs 스톨 8.7px — 스톨은 신호 자체가 없음 |
| **고정 카메라** | ✅ **필수** | 핸드헬드 시 추적 과분할(트랙/마릿수 20배↑) |

추적 과분할의 주원인은 카메라 흔들림이 아니라 **탐지 명멸**(3.02마리/프레임)이었고,
`conf 0.25 + max_age 40` 으로 **과분할 59% 개선**했다(모션 보상은 14%에 그침).

## 한계와 향후 (정직한 기술)

- **발정 판정 미완(원인 규명됨)**: 71471 [Bbox] 서브셋으로 실측한 결과, 카메라·개체를
  통제하면 AUC 0.465(무작위)로 **이 라벨로는 발정 판정이 불가**함을 확인했다. 발정
  지시 행동이 주석에 없는 것이 원인. → 원천 동영상 또는 외음부 이미지 원천이 필요.
- **행동 인식 0.516**: 미묘 행동(fight·sitting) 혼동은 남음. → 시퀀스(LSTM) 여지.
  방향은 실측으로 확정됐다 — 정지 프레임 피처는 천장(71471 자세 44차원 0.596 ≈
  행동 4종 0.619)이고 **시간 축이 효과**(롤링 윈도우 +0.042, 모션 기반 활동/휴식 0.739).
- **도메인 격차**: 케글은 영국 연구용 우리, 국내 상용 돈방과 차이. 교차-데이터셋
  일반화 ~0.41. → 국내 데이터 파인튜닝 필요.
- **Re-ID 한계**: 고전 외형 Re-ID는 위치 게이트로 오병합을 막았으나 잔여 단편화
  존재. → 메트릭 러닝 여지.
