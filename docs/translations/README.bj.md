**# पहिला योगदान**

शुरुआत में कवनो काम करे में कठिनाई होला। खास करके जब हमनी सभे मिलके काम करत बानी, त गलती होखल स्वाभाविक बा। बाकिर एक-दूसरा से मिले-जुले के आ मिलके काम करे के नामे त मुक्त स्रोत (Open Source) के असली बात बा। हम रउआ के पहिला मुक्त स्रोत योगदान (Contribution) आसान तरीका से करे में मदद करब।

लेख पढ़ला आ ट्यूटोरियल देखला से रउआ के मदद मिल सकेला, बाकिर असल में खुद अभ्यास करे से बढ़िया का हो सकेला? एह प्रोजेक्ट के मकसद नवसिखुआ लोग के आपन पहिला योगदान देवे के आसान तरीका से जानकारी देल बा। अगर रउआ आपन पहिला योगदान देत बानी, त नीचे दिहल कदम के पालन करीं।

**####** *\*अगर रउआ कमांड लाइन (CLI) के इस्तेमाल करे में सहज नइखी, त [GUI टूल इस्तेमाल करे के ट्यूटोरियल इहाँ बा।]\(#दोसर-साधन-इस्तेमाल-करे-के-ट्यूटोरियल)\**



[\<img src="[https://firstcontributions.github.io/assets/Readme/pirate.png](https://firstcontributions.github.io/assets/Readme/pirate.png)" width="22">]\(translations/README.en-pirate.md)

\<img align**=**"right" *width***=**"300" *src***=**"[https://firstcontributions.github.io/assets/Readme/fork.png](https://firstcontributions.github.io/assets/Readme/fork.png)" *alt***=**"एह रिपॉजिटरी के फोर्क करीं" />

अगर रउआ के मशीन पर Git नइखे, त [इहाँ से इंस्टॉल करीं]\([https://help.github.com/articles/set-up-git/](https://help.github.com/articles/set-up-git/)).

**## रिपॉजिटरी (Repository) के फोर्क (Fork) करीं**

फोर्क (fork) बटन पर क्लिक करके एह रिपो (repository) के फोर्क करीं।

एहसे रउआ के खाता में एह रिपॉजिटरी के एगो कॉपी बन जाई।

**## रिपॉजिटरी (Repository) के क्लोन (Clone) करीं**

\<img align**=**"right" *width***=**"300" *src***=**"[https://firstcontributions.github.io/assets/Readme/clone.png](https://firstcontributions.github.io/assets/Readme/clone.png)" *alt***=**"एह रिपॉजिटरी के क्लोन करीं" />

अब फोर्क कइल रिपो के अपना कंप्यूटर पर क्लोन करीं। एह खातिर अपना GitHub खाता पर जाईं। जे रिपो रउआ फोर्क कइले बानी, ओकरा के खोलीं। खुलल रिपो में दाहिना ओर ऊपर **\`**Clone or download**\`** बटन देखाई दी, ओकरा पर क्लिक करीं। फेर उहाँ **\`**Copy to clipboard**\`** वाला आइकन पर क्लिक करीं। एहसे एह रिपो के लिंक (URL) कॉपी हो जाई।

अब आपन टर्मिनल (Terminal) खोलीं आ ओहमें नीचे दिहल git कमांड (Command) चलाईं।

***\`\`\`Bash***

git clone **<**कॉपी-कइल-लिंक**>**

***\`\`\`***

\<img align**=**"right" *width***=**"300" *src***=**"[https://firstcontributions.github.io/assets/Readme/copy-to-clipboard.png](https://firstcontributions.github.io/assets/Readme/copy-to-clipboard.png)" *alt***=**"URL क्लिपबोर्ड पर कॉपी करीं" />

इहाँ **\`**<कॉपी-कइल-लिंक>**\`** (त्रिकोण वाला कंस छोड़के) से मतलब ओही URL लिंक से बा, जे रउआ अभी कॉपी कइले बानी। ई URL लिंक पावे खातिर पिछला कदम के देखीं।

उदाहरण खातिर:

***\`\`\`Bash***

git clone [https://github.com/रउआ-के-यूजर-नाम/first-contributions.git](https://github.com/रउआ-के-यूजर-नाम/first-contributions.git)

***\`\`\`***

इहाँ **\`**रउआ-के-यूजर-नाम**\`** से मतलब रउआ के GitHub खाता के नाम (Username) से बा।

अब Enter (Enter/Return) बटन दबाईं। एहसे एह रिपो **\`**first-contributions**\`** के रउआ के कंप्यूटर पर कॉपी हो जाई।

**## ब्रांच (Branch) बनाईं।**

अपना टर्मिनल से अपना रिपो फोल्डर/डायरेक्टरी (Folder/Directory) में चलीं (अगर अबहीं ले ना गइल बानी त)।

***\`\`\`Bash***

cd first-contributions

***\`\`\`***

अब **\`**git checkout**\`** कमांड के इस्तेमाल करके एगो नया ब्रांच बनाईं।

***\`\`\`Bash***

git checkout -b **<**इहाँ आपन-ब्रांच-के-नाम-डालीं**>**

***\`\`\`***

उदाहरण:

***\`\`\`Bash***

git checkout -b add-rahul-thakare

***\`\`\`***

(हर ब्रांच के नाम में **\`**add**\`** शब्द होखल जरूरी नइखे, बाकिर ऊपर के उदाहरण में एकर इस्तेमाल ठीक बा, काहेकि एह शाखा के मकसद इहाँ आपन नाम सूची में जोड़े के बा।)

**## जरूरी बदलाव करीं आ ओकरा के कमिट (Commit) करीं।**

अब टेक्स्ट एडिटर में **\`**Contributors.md**\`** फाइल खोलीं आ ओहमें आपन नाम जोड़ीं। फाइल के शुरुआत या अंत में मत जोड़ीं। ओकरा में कहीं भी रख सकत बानी। अब फाइल सेव (Save) करीं।

\<img align**=**"right" *width***=**"450" *src***=**"[https://firstcontributions.github.io/assets/Readme/git-status.png](https://firstcontributions.github.io/assets/Readme/git-status.png)" *alt***=**"गिट के स्थिति" />

अब फेर टर्मिनल पर जाईं आ `git status` कमांड चलाईं, त रउआ के ओहमें कइल गइल बदलाव देखाई दी।

**\`**git add**\`** कमांड के इस्तेमाल करके बनावल ब्रांच में ई बदलाव जोड़ीं

***\`\`\`Bash***

git add Contributors.md

***\`\`\`***

अब **\`**git commit**\`** कमांड के इस्तेमाल करके अपना बदलाव के कमिट/सुरक्षित करीं।

***\`\`\`Bash***

git commit -m "Add <रउआ-के-नाम> to Contributors list"

***\`\`\`***

**\`**<रउआ-के-नाम>**\`** के जगह अपना नाम डालीं।

**## GitHub में अपना बदलाव पुश करीं।**

**\`**git push**\`** के इस्तेमाल करके अपना बदलाव पुश करीं

***\`\`\`Bash***

git push origin **<**रउआ-के-ब्रांच-के-नाम**>**

***\`\`\`***

**\`**<रउआ-के-ब्रांच-के-नाम>**\`** के जगह अपना ब्रांच के नाम डालीं।

**## समीक्षा खातिर अपना बदलाव सबमिट करीं।**

अगर रउआ अपना GitHub प्रोफाइल में अपना रिपो पर जाईं, त रउआ के **\`**Compare & pull request**\`** भेजे के विकल्प देखाई दी। ओकरा पर क्लिक करीं।

\<img *style***=**"float: right;" *src***=**"[https://firstcontributions.github.io/assets/Readme/compare-and-pull.png](https://firstcontributions.github.io/assets/Readme/compare-and-pull.png)" *alt***=**"पुल रिक्वेस्ट बनाईं" />

अब आपन **\`**Pull request**\`** सबमिट करीं।

\<img *style***=**"float: right;" *src***=**"[https://firstcontributions.github.io/assets/Readme/submit-pull-request.png](https://firstcontributions.github.io/assets/Readme/submit-pull-request.png)" *alt***=**"पुल रिक्वेस्ट सबमिट करीं" />

बहुत जल्द हम रउआ के बदलाव के एह प्रोजेक्ट के मुख्य ब्रांच में मिला देब। जब रउआ के बदलाव मर्ज हो जाई, त रउआ के ई-मेल मिली।

**## अब आगे का?**

बधाई! रउआ अभी-अभी *\_fork -> clone -> edit -> PR\_* वाला प्रक्रिया पूरा कइले बानी, जेकर सामना रउआ के एगो योगदानकर्ता (Contributor) के रूप में हमेशा करे के पड़ी!

अपना योगदान के जश्न मनाईं आ [इहाँ]\([https://firstcontributions.github.io/#social-share](https://firstcontributions.github.io/#social-share)) जा के अपना दोस्त आ फॉलो करे वाला लोग के साथे शेयर/साझा करीं।

अगर रउआ के कवनो मदद के जरूरत होखे या कवनो सवाल होखे, त रउआ हमनी के Slack टीम में शामिल हो सकेनी। [Slack टीम में शामिल होईं]\([https://join.slack.com/t/firstcontributors/shared_invite/zt-1hg51qkgm-Xc7HxhsiPYNN3ofX2_I8FA](https://join.slack.com/t/firstcontributors/shared_invite/zt-1hg51qkgm-Xc7HxhsiPYNN3ofX2_I8FA))।

अब रउआ दोसरा प्रोजेक्ट में भी आपन योगदान दे सकेनी। हमनी कुछ प्रोजेक्ट के सूची बनवले बानी, जहाँ रउआ आसान Issues से शुरुआत कर सकेनी। [इहाँ वेब ऐप में प्रोजेक्ट के सूची देखीं।]\([https://firstcontributions.github.io/#project-list](https://firstcontributions.github.io/#project-list))
