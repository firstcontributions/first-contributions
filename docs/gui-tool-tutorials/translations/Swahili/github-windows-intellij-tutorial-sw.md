# Michango ya Kwanza

| <img alt="IntelliJ IDEA" src="https://upload.wikimedia.org/wikipedia/commons/9/9c/IntelliJ_IDEA_Icon.svg" width="40"> | IntelliJ IDEA |
| --- | --- |

Ni vigumu. Mara ya kwanza unapofanya jambo huwa vigumu kila wakati. Hasa unaposhirikiana na wengine, kufanya makosa hakujisikii vizuri. Lakini open source inahusu kushirikiana na kufanya kazi pamoja. Tunataka kurahisisha jinsi wachangiaji wapya wa open source wanavyojifunza na kuchangia kwa mara ya kwanza.

Kusoma makala na kutazama mafunzo kunaweza kusaidia, lakini hakuna bora kuliko kufanya mwenyewe bila kuharibu chochote. Mradi huu unalenga kutoa mwongozo na kurahisisha njia kwa wanaoanza kutoa mchango wao wa kwanza. Kumbuka: kadiri unavyokuwa mtulivu, ndivyo unavyojifunza vizuri zaidi. Ikiwa unataka kutoa mchango wako wa kwanza, fuata hatua rahisi zilizo hapa chini. Tunaahidi itakuwa ya kufurahisha.

Ikiwa huna IntelliJ IDEA kwenye kompyuta yako, [isakinishe](https://www.jetbrains.com/idea/download/#section=windows).

**Kumbuka:** Mafunzo haya yalitengenezwa kwa kutumia IntelliJ IDEA (toleo la 2019.3.2) kwenye kompyuta yenye Windows 10. Baadaye katika mafunzo haya tutatumia baadhi ya njia za mkato za kibodi. Hizi zinaweza kutofautiana kwenye mifumo mingine ya uendeshaji (macOS/Linux).

## Fork repositori hii

<img align="right" width="300" src="https://firstcontributions.github.io/assets/gui-tool-tutorials/github-desktop-tutorial/fork.png" alt="fork repositori hii" />

Fork repositori hii kwa kubofya kitufe cha `Fork` kilicho upande wa juu kulia wa ukurasa huu. Hii itatengeneza nakala ya repositori hii katika akaunti yako ya GitHub.

GitHub hufuatilia uhusiano kati ya repositori yako na ile uliyoifork. Unaweza kuichukulia repositori yako kama nakala yako ya kufanyia kazi.

Repositori nyingi za GitHub za kiwango cha juu zina timu ndogo ya watu wanaoweza kufanya commit za mabadiliko moja kwa moja. Wachangiaji wengine lazima wafork repositori, wafanye mabadiliko kwenye fork yao, kisha watengeneze Pull Request ili kuomba mabadiliko yao yaunganishwe tena kwenye repositori ya kiwango cha juu. Msimamizi wa repositori hiyo akiyakubali mabadiliko, yataunganishwa—na utapata sifa na bahati papo hapo! Zaidi kuhusu hilo baadaye.

## Clone repositori yako

<img align="right" width="300" src="https://firstcontributions.github.io/assets/Readme/clone.png" alt="clone repositori hii" />

Hatua inayofuata ni ku-clone repositori yako kwenye kompyuta yako ili uweze kuanza kufanya mabadiliko. IntelliJ IDEA inahitaji URL ya repositori yako, kwa hiyo bofya kitufe cha `Clone` kisha bofya ikoni ya `Copy to clipboard`.

**TAHADHARI:** Kosa la kawaida kwa wachangiaji wapya ni ku-clone repositori waliyofork kutoka badala ya ku-clone repositori yao wenyewe. Angalia address bar ya kivinjari chako na uhakikishe una-clone repositori yako.

Sasa fungua IntelliJ IDEA.

IntelliJ IDEA hukuruhusu ku-check out (kwa istilahi za Git, ku-clone) repositori iliyopo na kuunda mradi mpya kwa kutumia data uliyopakua.

Kutoka kwenye menyu kuu, chagua `VCS | Get from Version Control`, au kama hakuna mradi uliofunguliwa, bofya `Get from Version Control` kwenye skrini ya Welcome.

Kwenye kisanduku cha `Get from Version Control`, weka URL ya repositori ya mbali unayotaka ku-clone. Unaweza kubofya `Test` ili kuhakikisha kuwa muunganisho unaweza kuanzishwa. Pia unaweza kuchagua huduma mojawapo ya VCS upande wa kushoto. Ikiwa tayari umeingia kwenye huduma uliyochagua, utaonyeshwa orodha ya repositori zinazopatikana za ku-clone.

Bofya `Clone`. Ikiwa unataka kuunda mradi wa IntelliJ IDEA kwa kutumia sources ulizo-clone, bofya `Yes` kwenye kisanduku cha uthibitisho. Git root mapping itawekwa moja kwa moja kwenye root ya mradi.

Ikiwa mradi wako una submodules, nazo zita-clone na kusajiliwa moja kwa moja kama project roots.

**Muhimu:** Hakikisha ni repositori yako ya fork, siyo ya asili; vinginevyo haitafanya kazi.

## Unda branch

Katika Git, branching ni utaratibu muhimu unaokuruhusu kuacha mstari mkuu wa maendeleo kwa muda, kwa mfano unapohitaji kufanya kazi kwenye feature au kuhifadhi hali fulani ya codebase kwa ajili ya release.

Katika IntelliJ IDEA, shughuli zote za branch hufanywa kwenye kidirisha cha `Git Branches`. Ili kukifungua, bofya Git widget kwenye Status bar au bonyeza `Ctrl+Shift+\``.

Jina la branch iliyo-checkout kwa sasa linaonyeshwa kwenye Git widget katika Status bar.

Kwenye kidirisha cha branches, chagua `New Branch`.

Kwenye kisanduku kinachofunguka, weka jina la branch. Hakikisha chaguo la `Checkout branch` limechaguliwa ikiwa unataka kuhamia kwenye branch hiyo.

Branch mpya itaanza kutoka `HEAD` ya sasa. Ikiwa unataka kuanzisha branch kutoka commit ya awali badala ya `HEAD` ya branch ya sasa, chagua commit hiyo kwenye kichupo cha `Log` cha Version Control tool window kwa `Alt+9`, kisha chagua `New Branch` kwenye context menu.

## Fanya mabadiliko yanayohitajika

Fungua `Contributors.md` na uongeze jina lako mahali popote kwenye faili. Faili hili lina GFM (GitHub Flavored Markdown), ambayo ni aina ya markdown syntax.

Nakili mstari wa mmoja wa wachangiaji wengine na ubadilishe kwa jina lako ili kuhakikisha syntax iko sahihi—inaweza kuwa makini kidogo.

## Commit na Push mabadiliko kwenye GitHub

Chagua faili unazotaka ku-commit au changelist nzima kwenye kichupo cha `Local Changes` cha Version Control tool window kwa `Alt+9`, kisha bonyeza `Ctrl+K` au bofya kitufe cha `Commit` kwenye toolbar.

Kisanduku cha `Commit Changes` kinachofunguka kinaorodhesha faili zote zilizobadilishwa tangu commit ya mwisho, pamoja na faili mpya ambazo hazijaongezwa kwenye version control.

Weka commit message yenye maana.

Unaweza kubofya `Commit Message history` au kubonyeza `Ctrl+M` ili kuchagua kutoka kwenye orodha ya commit messages za hivi karibuni.

Unaweza pia kuhariri commit message kabla hujafanya push ya commit.

Bonyeza `Ctrl+Shift+K` au chagua `VCS | Git | Push` kutoka kwenye menyu kuu. Kisanduku cha `Push Commits` kitafunguka na kuonyesha repositori zote za Git, pamoja na commits zilizofanywa kwenye branch ya sasa tangu push ya mwisho.

## Tuma mabadiliko yako yakaguliwe

Katika hatua hii umekamilisha mabadiliko yako, lakini bado yapo kwenye repositori yako pekee. Hatua hii inaonyesha jinsi ya kutuma ombi kwa msimamizi wa repositori ya kiwango cha juu ili kuunganisha mabadiliko yako.

Kwenye repositori yako ya GitHub utaona kitufe cha `Compare & pull request` karibu na taarifa ya branch mpya. Bofya kitufe hicho.

<img src="https://firstcontributions.github.io/assets/gui-tool-tutorials/github-desktop-tutorial/compare-and-pull.png" alt="tengeneza pull request" />

Sasa tuma Pull Request.

<img src="https://firstcontributions.github.io/assets/gui-tool-tutorials/github-desktop-tutorial/submit-pull-request.png" alt="tuma pull request" />

Hivi karibuni mabadiliko yako yataunganishwa kwenye branch kuu ya mradi huu. Utapata barua pepe ya taarifa baada ya mabadiliko kuunganishwa.
