# Mchango wa Kwanza

| <img alt="IntelliJ IDEA" src="https://upload.wikimedia.org/wikipedia/commons/9/9c/IntelliJ_IDEA_Icon.svg" width="40"> | IntelliJ IDEA |
| ------------------------------------------------------------------------------------------------------------------------------------ | ------------------ |

Ni vigumu. Mara zote ni vigumu kufanya jambo kwa mara ya kwanza. Hasa unaposhirikiana na wengine, kufanya makosa kunaweza kukukosesha raha. Lakini chanzo huria kinahusu ushirikiano na kufanya kazi pamoja. Tulitaka kurahisisha namna wachangiaji wapya wa chanzo huria wanavyojifunza na kuchangia kwa mara ya kwanza.

Kusoma makala na kutazama video za mafunzo kunaweza kusaidia, lakini kujifunza kwa kufanya jambo lenyewe ni bora zaidi. Mradi huu unalenga kutoa mwongozo na kurahisisha namna wanaoanza wanavyoweza kutoa mchango wao wa kwanza. Kumbuka, unapokuwa mtulivu, utajifunza vizuri zaidi. Ikiwa unataka kutoa mchango wako wa kwanza, fuata hatua rahisi zilizo hapa chini. Tunaahidi, itafurahisha.

Ikiwa huna IntelliJ IDEA kwenye kompyuta yako, [isakinishe](https://www.jetbrains.com/idea/download/#section=windows).

**Dokezo:** Mafunzo haya yalitayarishwa kwa kutumia IntelliJ IDEA (toleo la 2019.3.2) kwenye kompyuta ya Windows 10. Baadaye tutatumia mikato ya kibodi. Mikato hii inaweza kutofautiana kwenye mifumo mingine ya uendeshaji (macOS/Linux).

## Fanya fork ya hazina hii

<img align="right" width="300" src="https://firstcontributions.github.io/assets/gui-tool-tutorials/github-desktop-tutorial/fork.png" alt="fanya fork ya hazina hii" />

Fanya fork ya hazina hii kwa kubofya kitufe cha fork kilicho juu upande wa kulia wa ukurasa huu. Hii itatengeneza nakala ya hazina hii kwenye akaunti yako ya GitHub.

GitHub hufuatilia uhusiano kati ya hazina yako na ile uliyofanya fork kutoka kwayo. Unaweza kuichukulia hazina yako kama nakala ya kufanyia kazi.

Hazina nyingi kuu za GitHub (yaani, ambazo hazikufanywa fork kutoka hazina nyingine) huwa na timu ndogo ya msingi inayoweza kufanya commit moja kwa moja. Wachangiaji wengine hufanya fork ya hazina, hufanya mabadiliko kwenye nakala yao, kisha hutuma Pull Request ili kuomba mabadiliko yao yaunganishwe kwenye hazina kuu. Msimamizi wa hazina kuu akiidhinisha mabadiliko, yataunganishwa na utapata umaarufu na utajiri papo hapo! Tutaeleza zaidi kuhusu hilo baadaye.

## Fanya clone ya hazina yako

<img align="right" width="300" src="https://firstcontributions.github.io/assets/Readme/clone.png" alt="fanya clone ya hazina yako" />

Hatua inayofuata ni kufanya clone ya hazina yako kwenye kompyuta yako ili uanze kufanya mabadiliko. IntelliJ IDEA inahitaji URL ya hazina yako. Bofya kitufe cha "clone", kisha ubofye ikoni ya "copy to clipboard".

**TAHADHARI:** Kosa moja la kawaida kwa wachangiaji wapya ni kufanya clone ya hazina ambayo walifanya fork kutoka kwayo badala ya hazina yao wenyewe. Angalia sehemu ya anwani ya kivinjari chako na uhakikishe kuwa unafanya clone ya hazina yako.

Sasa fungua IntelliJ IDEA.

IntelliJ IDEA hukuwezesha kupata nakala ya hazina iliyopo na kuunda mradi mpya kutokana na faili ulizopakua.

Kwenye menyu kuu, chagua VCS | Get from Version Control. Ikiwa hakuna mradi uliofunguliwa, bofya Get from Version Control kwenye skrini ya Welcome.

Kwenye dirisha la Get from Version Control, weka URL ya hazina unayotaka kufanya clone (unaweza kubofya Test ili kuhakikisha kuwa muunganisho wa seva ya mbali unapatikana), au chagua mojawapo ya huduma za kupangisha hazina zilizo upande wa kushoto. Ikiwa tayari umeingia kwenye huduma uliyochagua, IntelliJ IDEA inaweza kupendekeza orodha ya hazina unazoweza kufanya clone.

Bofya Clone. Ikiwa unataka kuunda mradi wa IntelliJ IDEA kutokana na faili za hazina uliyoifanya clone, bofya Yes kwenye ujumbe wa uthibitisho. Mipangilio ya Git root itawekwa kiotomatiki kwenye folda kuu ya mradi.

Ikiwa mradi wako una submodule, nazo zitafanywa clone na kusajiliwa kiotomatiki kama root za mradi.

**Muhimu:** Hakikisha unatumia hazina uliyofanya fork, wala si hazina asilia, la sivyo haitafanya kazi.

## Tengeneza tawi

Kwenye Git, matawi hukuwezesha kutenganisha kazi yako na mstari mkuu wa maendeleo, kwa mfano, unapofanya kazi kwenye kipengele kipya au unapohifadhi hali fulani ya msimbo kwa ajili ya toleo.

Kwenye IntelliJ IDEA, shughuli zote za matawi hufanywa kupitia menyu ibukizi ya Git Branches. Ili kuifungua, bofya Git widget kwenye upau wa hali au bonyeza Ctrl+Shift+`.

Jina la tawi lililochaguliwa kwa sasa huonekana kwenye Git widget kwenye upau wa hali.

Kwenye menyu ibukizi ya matawi, chagua New Branch.

Kwenye dirisha litakalofunguka, weka jina la tawi na uhakikishe kuwa chaguo la Checkout branch limechaguliwa ikiwa unataka kubadilisha na kutumia tawi hilo.

Tawi jipya litaanzia kwenye HEAD ya sasa. Ikiwa unataka kulianzisha kutoka kwenye commit ya awali badala ya HEAD ya sasa, chagua commit hiyo kwenye kichupo cha Log cha dirisha la zana la Version Control (Alt+9), kisha chagua New Branch kwenye menyu ya muktadha.

## Fanya mabadiliko yanayohitajika

Fungua faili la `Contributors.md` na uongeze jina lako mahali popote ndani ya faili. Faili hili linatumia GFM (GitHub Flavored Markdown), aina ya sintaksia ya Markdown inayotumiwa na GitHub. [Soma zaidi kuhusu Markdown](https://en.wikipedia.org/wiki/Markdown).

Nakili mstari wa mmoja wa wachangiaji wengine na ubadilishe jina lake kwa lako ili kuhakikisha kuwa sintaksia iko sahihi. Sintaksia inaweza kuwa na masharti maalum.

## Fanya commit na push ya mabadiliko yako kwenye GitHub

Kwenye kichupo cha Local Changes cha dirisha la zana la Version Control (Alt+9), chagua faili unazotaka kufanya commit au orodha nzima ya mabadiliko, kisha bonyeza Ctrl+K au bofya kitufe cha Commit kwenye upau wa zana.

Dirisha la Commit Changes litakalofunguka litaorodhesha faili zote zilizobadilishwa tangu commit ya mwisho na faili mpya ambazo bado hazijafuatiliwa.

Andika ujumbe unaoeleweka wa commit.

Unaweza kubofya Commit Message history (Ctrl+M) ili kuchagua kwenye orodha ya ujumbe wa hivi karibuni wa commit.

Unaweza pia kuhariri ujumbe wa commit baadaye, kabla hujafanya push ya commit.

Bonyeza Ctrl+Shift+K au uchague VCS | Git | Push kwenye menyu kuu. Dirisha la Push Commits litafunguka, likionyesha hazina zote za Git (ikiwa mradi una zaidi ya hazina moja ya Git) na kuorodhesha commit zote zilizofanywa kwenye tawi la sasa tangu push ya mwisho.

## Wasilisha mabadiliko yako kwa ukaguzi

Kwa sasa mabadiliko yako yapo kwenye hazina yako pekee. Hatua hii itaonyesha jinsi ya kumwomba msimamizi wa hazina kuu ayakubali na kuyaunganisha.

Kwenye hazina yako ya GitHub, utaona kitufe cha `Compare & pull request` karibu na taarifa ya tawi jipya. Bofya kitufe hicho.

<img src="https://firstcontributions.github.io/assets/gui-tool-tutorials/github-desktop-tutorial/compare-and-pull.png" alt="unda Pull Request" />

Sasa wasilisha Pull Request.

<img src="https://firstcontributions.github.io/assets/gui-tool-tutorials/github-desktop-tutorial/submit-pull-request.png" alt="wasilisha Pull Request" />

Hivi karibuni nitakuwa ninaunganisha mabadiliko yako kwenye tawi kuu la mradi huu. Utapokea arifa kwa barua pepe mabadiliko yatakapokuwa yameunganishwa.

## Uende wapi baada ya hapa?

Hongera! Umekamilisha mtiririko wa kawaida wa _fork -> clone -> edit -> PR_ ambao utakutana nao mara nyingi unapochangia!

Sherehekea mchango wako na uwashirikishe marafiki na wafuasi wako kwa kutembelea [tovuti](https://firstcontributions.github.io#social-share).
