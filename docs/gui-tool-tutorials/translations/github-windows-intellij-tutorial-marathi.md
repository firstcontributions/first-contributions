# प्रथम योगदान

<img alt="IntelliJ IDEA" src="https://upload.wikimedia.org/wikipedia/commons/9/9c/IntelliJ_IDEA_Icon.svg" width="40"> IntelliJ IDEA

पहिल्यांदा काहीतरी करणे नेहमीच कठीण असते. विशेषतः जेव्हा तुम्ही इतरांसोबत सहयोग (collaboration) करत असता, तेव्हा चुका होण्याची भीती वाटू शकते. पण मुक्त स्रोत (Open Source) प्रकल्प हे सहकार्य आणि एकत्र काम करण्याबद्दल असतात. आम्हाला नवीन मुक्त स्रोत योगदानकर्त्यांना त्यांचे पहिले योगदान देणे सोपे व्हावे यासाठी हे मार्गदर्शन तयार करायचे होते.

लेख वाचणे आणि ट्युटोरियल पाहणे उपयुक्त ठरते, परंतु प्रत्यक्ष काम करून शिकण्यासारखे दुसरे काही नाही. हा प्रकल्प नवशिक्यांना त्यांचे पहिले योगदान सोप्या पद्धतीने करता यावे यासाठी मार्गदर्शन करतो. लक्षात ठेवा, तुम्ही जितके शांत आणि आत्मविश्वासाने शिकाल तितके चांगले शिकाल. जर तुम्ही तुमचे पहिले योगदान देण्याचा विचार करत असाल, तर खाली दिलेल्या सोप्या पायऱ्या अनुसरा. आम्ही खात्री देतो की हा अनुभव आनंददायी असेल.

जर तुमच्या संगणकावर IntelliJ IDEA स्थापित नसेल, तर प्रथम ते स्थापित करा.

> **टीप:** हे ट्युटोरियल Windows 10 वर IntelliJ IDEA (Version 2019.3.2) वापरून तयार करण्यात आले आहे. या ट्युटोरियलमध्ये काही कीबोर्ड शॉर्टकट वापरले आहेत. ते macOS किंवा Linux सारख्या इतर ऑपरेटिंग सिस्टीमवर वेगळे असू शकतात.
## हे रिपॉझिटरी Fork करा

<img align="right" width="300" src="https://firstcontributions.github.io/assets/gui-tool-tutorials/github-desktop-tutorial/fork.png" alt="fork this repository" />

या पानाच्या वरच्या उजव्या कोपऱ्यात असलेल्या **Fork** बटणावर क्लिक करून हे रिपॉझिटरी Fork करा. यामुळे या रिपॉझिटरीची एक प्रत (copy) तुमच्या GitHub खात्यात तयार होईल.

GitHub तुमच्या Fork केलेल्या रिपॉझिटरी आणि मूळ रिपॉझिटरीमधील संबंध जतन करून ठेवतो. तुम्ही तुमच्या रिपॉझिटरीला काम करण्यासाठीची प्रत (working copy) समजू शकता.

बहुतेक GitHub रिपॉझिटरींमध्ये (ज्या इतर कोणत्याही रिपॉझिटरीवरून Fork केलेल्या नसतात) मुख्य टीम असते जी थेट बदल (commit) करू शकते. इतर सर्व योगदानकर्त्यांनी रिपॉझिटरी Fork करायची, त्या Fork मध्ये बदल करायचे आणि नंतर Pull Request तयार करून ते बदल मूळ रिपॉझिटरीमध्ये समाविष्ट करण्याची विनंती करायची असते.

जर मुख्य रिपॉझिटरीचे व्यवस्थापक (maintainer) तुमचे बदल मंजूर करतील, तर ते मुख्य प्रकल्पात समाविष्ट केले जातील. पुढील भागात आपण Pull Request कसा तयार करायचा ते पाहू.
## तुमचे रिपॉझिटरी Clone करा

<img align="right" width="300" src="https://firstcontributions.github.io/assets/Readme/clone.png" alt="clone this repository" />

पुढील टप्पा म्हणजे तुमचे रिपॉझिटरी तुमच्या संगणकावर Clone करणे, जेणेकरून तुम्ही त्यामध्ये बदल करण्यास सुरुवात करू शकाल. IntelliJ IDEA ला तुमच्या रिपॉझिटरीचा URL आवश्यक असतो. त्यामुळे GitHub वर **Clone** बटणावर क्लिक करा आणि **Copy to clipboard** या चिन्हावर क्लिक करून URL कॉपी करा.

> **सावधान:** नवीन योगदानकर्त्यांकडून होणारी एक सामान्य चूक म्हणजे ते स्वतःच्या Fork केलेल्या रिपॉझिटरीऐवजी मूळ (Original) रिपॉझिटरी Clone करतात. तुमच्या ब्राउझरच्या Address Bar मध्ये URL तपासा आणि तुम्ही तुमचे Fork केलेले रिपॉझिटरीच Clone करत आहात याची खात्री करा.

आता IntelliJ IDEA उघडा.

IntelliJ IDEA तुम्हाला विद्यमान Git रिपॉझिटरी Clone करण्याची आणि डाउनलोड केलेल्या स्रोत कोडवर आधारित नवीन प्रकल्प तयार करण्याची सुविधा देते.

मुख्य मेनूमधून **VCS → Get from Version Control** निवडा. जर कोणताही प्रकल्प उघडलेला नसेल, तर Welcome Screen वरील **Get from Version Control** पर्यायावर क्लिक करा.

**Get from Version Control** या डायलॉगमध्ये तुम्हाला Clone करायच्या Remote Repository चा URL द्या. **Test** बटणावर क्लिक करून कनेक्शन तपासू शकता. किंवा डाव्या बाजूला उपलब्ध असलेल्या VCS Hosting Services मधून रिपॉझिटरी निवडू शकता.

**Clone** वर क्लिक करा. जर Clone केलेल्या स्रोत कोडवर आधारित IntelliJ IDEA प्रकल्प तयार करायचा असेल, तर Confirmation Dialog मध्ये **Yes** निवडा. Git Root Mapping आपोआप Project Root Directory वर सेट होईल.

जर तुमच्या प्रकल्पात Submodules असतील, तर ते देखील Clone होतील आणि आपोआप Project Roots म्हणून नोंदवले जातील.

> **महत्त्वाचे:** Clone करताना मूळ (Original) रिपॉझिटरी नव्हे, तर तुमचे **Fork केलेले रिपॉझिटरी** निवडले आहे याची खात्री करा. अन्यथा पुढील प्रक्रिया योग्य प्रकारे कार्य करणार नाही.
## नवीन Branch तयार करा

Git मध्ये Branching ही एक प्रभावी सुविधा आहे जी तुम्हाला मुख्य विकास शाखेपासून (main development line) वेगळे काम करण्याची परवानगी देते. उदाहरणार्थ, नवीन फीचर विकसित करणे किंवा एखाद्या विशिष्ट आवृत्तीची स्थिती जतन करणे.

IntelliJ IDEA मध्ये Branch संबंधित सर्व क्रिया **Git Branches** पॉपअपमधून केल्या जातात. ते उघडण्यासाठी Status Bar मधील **Git Widget** वर क्लिक करा किंवा **Ctrl + Shift + `** हा शॉर्टकट वापरा.

सध्या Checkout केलेल्या Branch चे नाव Status Bar मधील Git Widget मध्ये दिसेल.

Branches पॉपअपमध्ये **New Branch** निवडा.

उघडणाऱ्या डायलॉगमध्ये नवीन Branch चे नाव द्या. जर तुम्हाला लगेच त्या Branch वर स्विच करायचे असेल, तर **Checkout branch** हा पर्याय निवडलेला आहे याची खात्री करा.

नवीन Branch सध्याच्या **HEAD** पासून तयार होईल. जर तुम्हाला सध्याच्या Branch ऐवजी आधीच्या Commit पासून Branch तयार करायची असेल, तर **Version Control** Tool Window मधील **Log** टॅब (Alt + 9) उघडा, आवश्यक Commit निवडा आणि Context Menu मधून **New Branch** निवडा.
## आवश्यक बदल करा

`Contributors.md` ही फाइल उघडा आणि त्यामध्ये कुठेही तुमचे नाव जोडा. ही फाइल **GFM (GitHub Flavored Markdown)** वापरते, जी Markdown ची GitHub साठीची विशेष आवृत्ती आहे.

योग्य स्वरूप (syntax) राखण्यासाठी इतर कोणत्याही योगदानकर्त्याची एक ओळ कॉपी करा आणि त्यामध्ये तुमचे नाव टाका. Markdown चे स्वरूप थोडे कठोर असू शकते, त्यामुळे काळजीपूर्वक संपादन करा.
## GitHub वर बदल Commit आणि Push करा

**Version Control** Tool Window (Alt + 9) मधील **Local Changes** टॅबमध्ये Commit करायच्या फाइल्स किंवा संपूर्ण Changelist निवडा. त्यानंतर **Ctrl + K** दाबा किंवा Toolbar वरील **Commit** बटणावर क्लिक करा.

उघडणाऱ्या **Commit Changes** डायलॉगमध्ये मागील Commit नंतर बदललेल्या सर्व फाइल्स आणि नवीन जोडलेल्या (Unversioned) फाइल्सची यादी दिसेल.

योग्य आणि अर्थपूर्ण **Commit Message** लिहा.

अलीकडील Commit Messages मधून निवडण्यासाठी **Ctrl + M** दाबू शकता.

Commit Push करण्यापूर्वी तुम्ही Commit Message बदलू शकता.

यानंतर **Ctrl + Shift + K** दाबा किंवा **VCS → Git → Push** निवडा.

**Push Commits** डायलॉगमध्ये तुमच्या Branch मधील Push न झालेले सर्व Commits दिसतील. त्यानंतर **Push** वर क्लिक करून तुमचे बदल GitHub वर पाठवा.
## तुमचे बदल पुनरावलोकनासाठी (Review) सबमिट करा

या टप्प्यावर तुम्ही तुमचे बदल पूर्ण केले आहेत, पण ते अजूनही फक्त तुमच्या रिपॉझिटरीमध्ये आहेत. आता हे बदल मुख्य रिपॉझिटरीच्या व्यवस्थापकाला (maintainer) Merge करण्यासाठी विनंती कशी करायची ते पाहू.

GitHub वरील तुमच्या रिपॉझिटरीमध्ये नवीन Branch च्या सूचनेजवळ **Compare & pull request** हे बटण दिसेल. त्यावर क्लिक करा.

<img src="https://firstcontributions.github.io/assets/gui-tool-tutorials/github-desktop-tutorial/compare-and-pull.png" alt="create a pull request" />

आता **Pull Request** सबमिट करा.

<img src="https://firstcontributions.github.io/assets/gui-tool-tutorials/github-desktop-tutorial/submit-pull-request.png" alt="submit pull request" />

लवकरच या प्रकल्पाचा व्यवस्थापक तुमचे बदल मुख्य Branch मध्ये Merge करेल. Merge झाल्यानंतर तुम्हाला ई-मेलद्वारे सूचना मिळेल.

## पुढे काय?

अभिनंदन! 🎉

तुम्ही यशस्वीरित्या **Fork → Clone → Edit → Pull Request** ही Open Source मधील महत्त्वाची प्रक्रिया पूर्ण केली आहे.

तुमच्या पहिल्या योगदानाचा आनंद साजरा करा आणि ते तुमच्या मित्रांसोबत व सोशल मीडियावर शेअर करा.
