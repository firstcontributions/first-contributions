# प्रथम योगदान (First Contributions)

| <img alt="IntelliJ IDEA" src="https://upload.wikimedia.org/wikipedia/commons/9/9c/IntelliJ_IDEA_Icon.svg" width="40"> | IntelliJ IDEA |
| ------------------------------------------------------------------------------------------------------------------------------------ | ------------------ |


हे कठीण असते. जेव्हा तुम्ही पहिल्यांदा काहीतरी करता तेव्हा ते नेहमीच कठीण वाटते. विशेषतः जेव्हा तुम्ही इतरांसोबत काम (collaborate) करत असता, तेव्हा चुका करणे सोपे नसते. परंतु मुक्त स्रोत (Open Source) म्हणजे सहकार्य आणि एकत्र काम करणे. नवीन ओपन-सोर्स योगदानकर्त्यांनी (contributors) पहिल्यांदा कसे शिकावे आणि योगदान द्यावे हे सोपे करणे हा आमचा हेतू आहे.

लेख वाचणे आणि ट्यूटोरियल पाहणे उपयुक्त ठरू शकते, परंतु प्रत्यक्ष काम करून पाहणे हा शिकण्याचा सर्वोत्तम मार्ग आहे. या प्रकल्पाचे उद्दिष्ट मार्गदर्शन करणे आणि नवशिक्यांना त्यांचे प्रथम योगदान देणे सुलभ करणे हे आहे. लक्षात ठेवा, तुम्ही जितके शांत राहाल तितके चांगले शिकाल. तुम्हाला तुमचे पहिले योगदान करायचे असल्यास, खालील सोप्या चरणांचे अनुसरण करा. तुम्हाला नक्कीच आनंद येईल.

तुमच्या संगणकावर IntelliJ IDEA नसल्यास, [येथून स्थापित करा](https://www.jetbrains.com/idea/download/#section=windows).

**टीप:** हे ट्यूटोरियल Windows 10 मशीनवर IntelliJ IDEA (आवृत्ती 2019.3.2) वापरून तयार करण्यात आले आहे. या ट्यूटोरियलमध्ये पुढे काही कीबोर्ड शॉर्टकट वापरले जातील, जे इतर ऑपरेटिंग सिस्टीमवर (macOS/Linux) वेगळे असू शकतात.

## हे रिपॉझिटरी फोर्क (Fork) करा

<img align="right" width="300" src="https://firstcontributions.github.io/assets/gui-tool-tutorials/github-desktop-tutorial/fork.png" alt="fork this repository" />

या पृष्ठाच्या वरील उजव्या कोपऱ्यात असलेल्या **Fork** बटणावर क्लिक करून हे रेपॉजिटरी फोर्क करा. यामुळे तुमच्या GitHub खात्यामध्ये या रेपॉजिटरीची एक प्रत तयार होईल.

GitHub तुमच्या रेपोमधील आणि मूळ रेपोमधील संबंधाचा मागोवा ठेवते. तुम्ही तुमच्या रेपोला एक कार्यरत प्रत (working copy) मानू शकता.

बहुतेक उच्च-स्तरीय GitHub रेपॉजिटरीजमध्ये थेट बदल कमिट करण्यासाठी एक छोटी मुख्य टीम असते. इतर सर्व योगदानकर्त्यांनी रेपो फोर्क करणे आवश्यक आहे आणि फोर्कमध्ये बदल करून मुख्य रेपोमध्ये बदल समाविष्ट करण्यासाठी 'Pull Request' तयार करावी लागते. प्रशासकाने बदल मंजूर केल्यास ते मुख्य कोडमध्ये विलीन (merge) केले जातात.

## तुमचे रिपॉझिटरी क्लोन करा

<img align="right" width="300" src="https://firstcontributions.github.io/assets/Readme/clone.png" alt="clone this repository" />

पुढील पायरी म्हणजे तुमच्या मशीनवर रेपो क्लोन करणे. IntelliJ IDEA ला तुमच्या रेपोच्या URL ची आवश्यकता असते. म्हणून हिरव्या रंगाच्या **Code** / **Clone** बटणावर क्लिक करा आणि "Copy to clipboard" आयकॉनवर क्लिक करा.

**सावधान:** नवीन योगदानकर्ते अनेकदा मूळ रेपो क्लोन करण्याची चूक करतात. तुमच्या ब्राउझरचा ॲड्रेस बार तपासा आणि तुम्ही तुमच्या स्वतःच्या GitHub खात्यावरील फोर्क केलेला रेपो क्लोन करत आहात याची खात्री करा.

आता IntelliJ IDEA उघडा.

IntelliJ IDEA तुम्हाला विद्यमान रेपॉजिटरी चेक आउट (Git संज्ञेनुसार clone) करण्याची आणि डाउनलोड केलेल्या डेटावर आधारित नवीन प्रकल्प तयार करण्याची अनुमती देते.

मुख्य मेनूमधून **VCS | Get from Version Control** निवडा, किंवा कोणताच प्रकल्प उघडलेला नसल्यास Welcome स्क्रीनवर **Get from Version Control** वर क्लिक करा.

Get from Version Control डायलॉग बॉक्समध्ये, तुम्ही कॉपी केलेली रिमोट रेपॉजिटरीची URL पेस्ट करा (कनेक्शन स्थापित झाले आहे हे तपासण्यासाठी तुम्ही 'Test' वर क्लिक करू शकता).

**Clone** वर क्लिक करा. क्लोन केलेल्या कोडवर आधारित IntelliJ IDEA प्रोजेक्ट तयार करायचा असल्यास कन्फर्मेशन डायलॉगमध्ये **Yes** निवडा. Git root mapping आपोआप प्रोजेक्टच्या रूट डिरेक्टरीवर सेट होईल.

तुमच्या प्रोजेक्टमध्ये सबमोड्यूल्स असल्यास ते देखील आपोआप क्लोन आणि रजिस्टर होतील.

**महत्त्वाचे:** तुम्ही तुमच्या फोर्क केलेल्या रिपॉझिटरीचीच लिंक वापरली आहे ना, मूळ रिपॉझिटरीची नाही, याची खात्री करा; अन्यथा तुम्हाला बदल पुश करता येणार नाहीत.

## नवीन शाखा (Branch) तयार करा

Git मध्ये ब्राँचिंग ही एक महत्त्वाची कार्यपद्धती आहे, ज्याद्वारे तुम्ही मुख्य डेव्हलपमेंट लाइनपासून वेगळे होऊन नवीन फिचरवर काम करू शकता.

IntelliJ IDEA मध्ये ब्राँचेसशी संबंधित सर्व कामे **Git Branches** पॉपअपमध्ये केली जातात. ते उघडण्यासाठी स्टेटस बारमधील Git विजेटवर क्लिक करा किंवा `Ctrl+Shift+\`` दाबा.

सध्या सक्रिय असलेल्या शाखेचे नाव स्टेटस बारमधील Git विजेटमध्ये दिसते.

ब्राँचेस पॉपअपमध्ये **New Branch** निवडा.

उघडलेल्या डायलॉग बॉक्समध्ये शाखेचे नाव प्रविष्ट करा (उदा. `add-your-name`) आणि त्या शाखेत जाण्यासाठी **Checkout branch** पर्याय निवडलेला असल्याची खात्री करा. **Create** वर क्लिक करा.

## आवश्यक बदल करा

[`Contributors.md`](../../../Contributors.md) फाइल उघडा आणि त्या फाइलमध्ये कुठेही तुमचे नाव जोडा. ही फाइल GFM (GitHub Flavored Markdown) फॉरमॅटमध्ये आहे.

इतर कोणत्याही योगदानकर्त्याची ओळ कॉपी करा आणि वाक्यरचना (syntax) योग्य राहण्यासाठी त्यात तुमचे नाव व प्रोफाईल लिंक टाका.

## बदल Git वर Commit आणि Push करा

Version Control टूल विंडोच्या Local Changes टॅबमध्ये (`Alt+9`) जाऊन तुम्ही केलेले बदल निवडा आणि `Ctrl+K` दाबा किंवा टूलबारवरील **Commit** बटणावर क्लिक करा.

Commit Changes डायलॉग बॉक्समध्ये आवश्यक बदल तपासा आणि एक अर्थपूर्ण कमिट मेसेज लिहा (उदा. `Add <your-name> to Contributors list`).

त्यानंतर कमिट सेव्ह करण्यासाठी Commit वर क्लिक करा.

आता बदल GitHub वर पाठवण्यासाठी मुख्य मेनूमधून **VCS | Git | Push** निवडा किंवा `Ctrl+Shift+K` दाबा. Push Commits डायलॉग उघडेल; तिथे **Push** वर क्लिक करा.

## तुमचे बदल पुनरावलोकनासाठी पाठवा (Pull Request)

या टप्प्यावर तुमचे बदल तुमच्या स्वतःच्या GitHub रिपॉझिटरीमध्ये अपलोड झाले आहेत. आता मूळ रिपॉझिटरीमध्ये बदल विलीन करण्यासाठी Pull Request पाठवावी लागेल.

GitHub वर तुमच्या रिपॉझिटरी पेजवर जा. तिथे तुम्हाला नवीन शाखेच्या सूचनेसह **Compare & pull request** बटण दिसेल. त्यावर क्लिक करा.

<img src="https://firstcontributions.github.io/assets/gui-tool-tutorials/github-desktop-tutorial/compare-and-pull.png" alt="create a pull request" />

आता **Create pull request** बटणावर क्लिक करा.

<img src="https://firstcontributions.github.io/assets/gui-tool-tutorials/github-desktop-tutorial/submit-pull-request.png" alt="submit pull request" />

लवकरच मुख्य मेंटेनर्स तुमचे बदल तपासून ते मुख्य शाखेत समाविष्ट करतील. बदल विलीन झाल्यानंतर तुम्हाला ईमेलद्वारे सूचना मिळेल.

## आता पुढे काय?

अभिनंदन! तुम्ही ओपन सोर्समधील मानक **fork -> clone -> edit -> PR** ही संपूर्ण प्रक्रिया यशस्वीरीत्या पूर्ण केली आहे!

तुमचे हे योगदान साजरे करण्यासाठी [येथे वेब ॲपवर जा](https://firstcontributions.github.io#social-share) आणि तुमच्या मित्रांसोबत शेअर करा.
