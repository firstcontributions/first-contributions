

\# First Contribution — Git Command Cheat Sheet



This guide explains the basic Git commands used when making your first open-source contribution.



\## 1. Clone the repository



```bash

git clone https://github.com/YOUR-USERNAME/REPOSITORY.git

```



Downloads the repository to your local system.



\## 2. Navigate into the repository



```bash

cd REPOSITORY

```



Moves into the project directory.



\## 3. Create a new branch



```bash

git switch -c your-branch-name

```



Creates and switches to a new branch.



\## 4. Check your changes



```bash

git status

```



Displays the current state of your working directory.



\## 5. Stage your changes



```bash

git add filename

```



Adds a specific file to the staging area.



\## 6. Commit your changes



```bash

git commit -m "Describe your changes"

```



Records your changes with a descriptive message.



\## 7. Push your branch



```bash

git push -u origin your-branch-name

```



Uploads your branch to GitHub.



\## 8. Create a Pull Request



Open your fork on GitHub and click \*\*Compare \& pull request\*\* to submit your contribution for review.



\## Useful commands



```bash

git diff

```



Shows the changes made to files.



```bash

git branch

```



Lists local branches.



```bash

git log --oneline

```



Shows a compact commit history.



\*\*Tip:\*\* Always review your changes before committing.
